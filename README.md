### 実績
ETロボコン2025東海地区 フィジカル部門 3位 (チーム名：ミナミヤマRC)

### 主な取り組み

**ETロボコン 2026 / チーム 名南RC（Basic Class）**
- SPIKE-RT・TOPPERS/ASP3 上の C++ による自律走行システム
- 方向を考慮した Dijkstra による経路生成（全 4,872 通りのゲート構成で検証）
- シーン境界での位置バイアス補正（補正なし 1.21cm → 補正あり 0.90cm）
- OpenCV による走行軌跡のカメラ計測，BLE ログを用いた PID 解析・ARX システム同定

**自作 IoT / Web アプリ**
- Raspberry Pi 赤外線リモコンサーバー（Flask，MOSFET による GPIO 制御，オフライン動作対応）
- Raspberry Pi カメラサーバー（Python HTTP サーバー，LAN / VPN 両対応）
- レシート家計簿アプリ（OCR，IndexedDB，WebAuthn による削除ロック）
